## 🚀 Objetivo do Projeto

Criar uma presença digital profissional que:

- Apresente minhas habilidades técnicas e estratégicas
- Gere autoridade no mercado
- Converta visitantes em leads (contato via WhatsApp)
- Seja rápida, acessível e bem indexada pelos mecanismos de busca

---

## 🛠️ Tecnologias Utilizadas

### Front-end

- **HTML5** — Estrutura semântica e acessível
- **CSS3 (modularizado)** — Organização profissional por camadas
- **JavaScript (Vanilla)** — Interações, animações e UX
- **Bootstrap 5** — Grid, responsividade e componentes base
- **Bootstrap Icons** — Ícones vetoriais leves

### Animações & UX

- **AOS (Animate On Scroll)** — Animações suaves ao rolar a página
- **Intersection Observer API** — Animações performáticas
- **Scroll suave customizado**
- **Efeitos de hover e glow**

### SEO & Performance

- Meta tags completas (SEO, Open Graph e Twitter Cards)
- **Schema.org (JSON-LD)** para dados estruturados
- **Sitemap.xml**
- **Robots.txt**
- URL canônica
- Otimização para Core Web Vitals

### Deploy

- **Vercel** — Hospedagem rápida, estável e gratuita
